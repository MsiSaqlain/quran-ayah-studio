# Third-party attribution and licensing notes

## Quran data

Al Quran Cloud structured API: https://alquran.cloud/

The application retrieves `quran-uthmani` Arabic text at runtime and does not modify the source string.

Tanzil Project licensing reference: https://tanzil.net/docs/Text_License

Tanzil states that its Quran text is released under Creative Commons Attribution 3.0 with an explicit requirement not to change the text, to identify Tanzil as the source, and to link to tanzil.net.

## Font

Amiri / Amiri Quran: https://github.com/aliftype/amiri

License: SIL Open Font License 1.1.

## Translation

The app defaults to the API edition `en.itani` when available, but translation editions are selected dynamically from the API. Review the specific translation's upstream license before publishing or redistributing it.
